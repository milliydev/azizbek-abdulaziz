# Naruto Anime & Shop — сайт, админ-панель и Telegram-бот

Полноценная экосистема на **Node.js + Express**: аниме-стриминг, магазин мерча, админ-панель и Telegram-бот, связанные общей базой данных.

```
naruto-shop-anime-system/
├── server/
│   ├── index.js            # Express-сервер, запуск бота
│   ├── config.js           # чтение .env
│   ├── db.js / seed.js     # JSON-база (data/db.json) и демо-контент
│   ├── auth.js             # JWT-сессии, доступ админа только по ADMIN_EMAIL
│   ├── orders.js           # общая логика заказов (сайт + бот), цены считаются на сервере
│   ├── payments.js         # demo / Stripe
│   ├── routes/public.js    # API сайта: каталог, серии, заказы, трекинг, аккаунты, поддержка
│   ├── routes/admin.js     # API админки: CRUD товаров/серий/новостей, заказы, загрузка файлов
│   └── telegram/
│       ├── api.js          # клиент Bot API (native fetch, загрузка файлов)
│       ├── bot.js          # бот: магазин, корзина, оформление, серии, deep-links
│       └── notify.js       # уведомления администратору (ID из ADMIN_TELEGRAM_ID)
├── public/                 # сайт (SPA, 8 разделов, EN/RU, GSAP)
│   ├── index.html, css/, js/app.js, js/i18n.js, vendor/ (GSAP)
│   ├── admin/              # админ-панель
│   ├── img/                # фото товаров и превью серий (заглушки)
│   └── media/videos/       # демо-ролики (заглушки)
├── uploads/                # файлы, загруженные через админку
├── data/db.json            # создаётся автоматически при первом запуске
└── .env                    # настройки
```

## Быстрый старт

Нужен **Node.js 18.17+**.

```bash
npm install
npm start
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin — вход только для адреса из `ADMIN_EMAIL`, пароль — `ADMIN_PASSWORD` в файле `.env`.
- Бот запускается вместе с сервером (long polling, вебхук не нужен).

Сбросить базу к демо-контенту: `npm run reset-db`.

## ⚠️ Безопасность — сделайте сразу

1. **Перевыпустите токен бота.** Токен был отправлен в чат. В @BotFather: `/mybots` → бот → *API Token* → *Revoke*, вставьте новый в `TELEGRAM_BOT_TOKEN`.
2. **Смените пароль админа** в `ADMIN_PASSWORD` (сейчас там сгенерированный случайный пароль).
3. На продакшене используйте HTTPS и задайте `PUBLIC_URL=https://ваш-домен`.

## Настройки (.env)

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `ADMIN_TELEGRAM_ID` | **единственный** получатель уведомлений о заказах (your Telegram user ID) |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | вход в админку (другие email не принимаются) |
| `PUBLIC_URL` | адрес сайта; нужен боту для кнопок «на сайте» (для localhost кнопки скрываются) |
| `PAYMENT_MODE` | `demo` или `stripe` |
| `STRIPE_SECRET_KEY`, `STRIPE_PUBLISHABLE_KEY` | ключи Stripe для реальных платежей |
| `TELEGRAM_PAYMENT_PROVIDER_TOKEN` | токен платёжного провайдера из @BotFather → Payments (оплата картой прямо в боте) |
| `JWT_SECRET` | секрет сессий |

## Как работает

### Сайт (8 разделов)
Главная · Магазин (+ карточка товара) · Смотреть (плеер, список серий, автопереход) · Корзина и оформление · О нас · Новости · Поддержка (форма уходит админу в Telegram) · Личный кабинет (регистрация, история заказов, трекинг по номеру + телефону).
Переключатель языка EN/RU — выпадающий список в шапке. Анимации — GSAP + ScrollTrigger (интро, hero, reveal, 3D-tilt карточек, «полёт» товара в корзину, флип банковской карты).

### Серия → Telegram
На странице серии кнопка **«Отправить серию в бот»** открывает `t.me/<бот>?start=ep_<id>`. Бот присылает видео: локальный файл загружается в Telegram один раз, затем используется сохранённый `file_id` (мгновенно). Ограничение Bot API — 50 МБ на загрузку; для больших файлов бот присылает ссылку на просмотр на сайте.

### Оплата и уведомление администратору
После успешной оплаты сервер создаёт заказ (цены и сумма всегда пересчитываются на сервере) и отправляет на `ADMIN_TELEGRAM_ID`:
имя, телефон, адрес, геолокацию (ссылка на карту + точка на карте), список товаров **с фото, названием и ценой**, сумму и способ оплаты.

**Данные карты.** Полный номер карты и CVC **никогда** не отправляются на сервер, в базу или в Telegram — это требование PCI DSS и защита от утечек. Администратор видит только платёжную систему и последние 4 цифры.
- `demo` — карта проверяется в браузере (Luhn, срок, CVC), реального списания нет. Подходит для показа и тестов.
- `stripe` — реальные платежи: данные карты идут напрямую в Stripe, сервер проверяет PaymentIntent перед созданием заказа.
- Для Узбекистана можно подключить Payme / Click / Uzum по тому же принципу в `server/payments.js`.

### Telegram-бот
Меню: 🛍 Магазин · 🎬 Серии · 🛒 Корзина · 📦 Мои заказы · 🌐 Язык.
Карточка товара — фото, название, описание, цена и кнопки «В корзину» / «Купить сейчас». Оформление: имя → телефон (кнопка «Отправить номер») → геолокация или адрес → подтверждение → оплата картой (Telegram Payments, если задан провайдер) или при получении. Каждый заказ из бота пересылается на `ADMIN_TELEGRAM_ID`. Когда админ меняет статус заказа в админке, покупатель получает уведомление в боте.

### Админ-панель
Обзор (выручка, заказы) · Заказы (поиск, фильтр, смена статуса, карта, экспорт CSV) · Товары (фото, название RU/EN, описание, цена, категория, остаток) · Серии (загрузка видео с прогрессом или ссылка .mp4/YouTube, превью, номер, сезон) · Новости · Сообщения поддержки.

## Деплой на сервер (VPS)

```bash
npm install --omit=dev   # stripe ставится как optional
npm i -g pm2
pm2 start server/index.js --name naruto
pm2 save
```
Перед Node поставьте Nginx с HTTPS (Let's Encrypt) и `client_max_body_size 2g;` для загрузки видео. Запускайте **один** экземпляр бота — Telegram не позволяет двум процессам одновременно читать обновления.

## Контент и права

Фото товаров и видео в комплекте — **заглушки**. Замените их в админке своими фотографиями и **видео, на распространение которых у вас есть права** (лицензия, официальные embed-ссылки). Публикация чужих серий без лицензии нарушает авторские права и может привести к блокировке сайта и бота. Официальные логотипы и персонажи в дизайне не используются; проект оформлен как фан-магазин.

## Serversiz rejim (localStorage)

`public/index.html` faylini to'g'ridan-to'g'ri brauzerda ochsangiz yoki istalgan statik hostingga
(GitHub Pages, Netlify, Live Server) qo'ysangiz, sayt Node serversiz ishlaydi:
ro'yxatdan o'tish, kirish, savat, buyurtma va buyurtmani kuzatish brauzerning `localStorage`ida saqlanadi
(`public/js/local-api.js`, katalog: `public/js/seed-data.js`).

Server (`npm start`) ishlab tursa, sayt avtomatik ravishda serverdan foydalanadi.
Serversiz rejimda ma'lumotlar faqat shu brauzerda saqlanadi; admin panel va Telegram bot ishlamaydi.
